The Shopify search that understands your references

Test it first on your own site: search the same reference in three forms — M8x20, M8 x 20, M8-20. If the three result counts differ, this page is for you.

What native search can't do

No typo tolerance

Shopify's native search doesn't correct “wahser”. On a technical catalog where people type references on a keyboard, that's a dealbreaker.

Large catalogs

Beyond 5,000 products, native filters plateau — 25 filters maximum. That's exactly the size where a real engine becomes necessary.

Technical references

“M8x20” and “M8 x 20” remain two different strings to the native engine, semantic or not.

Where the Shopify integration stands

A theme extension exists

It intercepts search and queries Heurix, using a public key — never your server key, which visitors could read.

Rendering stays with Shopify

The goal is for Shopify to draw the grid itself with your theme, via its Section Rendering API — you rebuild nothing.

Transparency

The full app (one-click install from the App Store) requires Shopify's review and isn't published yet. If you're on Shopify with a technical catalog, let's talk: your specific case is exactly what will decide the timeline.

PrestaShop and WooCommerce are further along — if you have a choice of platform, integration is more direct there today.
